# Портфолио Kiglua — отдельные файлы

Сайт собран из простых файлов — работает без сборки и установки чего-либо.

## Файлы

- `index.html` — сама страница (профиль, обо мне, проекты, контакты)
- `style.css` — все стили и анимации
- `mountains.jpg` — фон с горами
- `avatar.jpg` — аватар (замени на своё фото)

## Как залить на GitHub Pages

1. Зайди в свой репозиторий `kiglua_bio` (или создай новый).
2. Загрузь все 4 файла в корень репозитория (замени старые).
3. Через минуту сайт обновится по адресу `https://kiglua.github.io/kiglua_bio/`.

## Что править под себя

- **Аватар:** просто замени файл `avatar.jpg` своим фото (квадратным).
- **Текст, проекты, ссылки:** открой `index.html` — всё подписано комментариями, меняй текст между тегами.
- **Ссылки:** в блоке «Контакты» поменяй адрес в `href="..."`.

Файл `style.css` трогать не нужно, если не хочешь менять цвета и размеры.
